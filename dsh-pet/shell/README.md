# dsh-pet-shell · 桌宠桌面壳（Windows）

让服务器上的桌宠**跳出浏览器标签、活在整个桌面上**的小壳：

- **全屏透明置顶窗**加载桌宠页（服务器地址），页面背景本身透明 → 宠物直接浮在真实桌面上，
  活动范围 = 整块屏幕（漫游 / 拖拽 / 角落定位都按屏幕算）
- **鼠标默认穿透**：平时完全不挡事，点桌面、点其它软件都正常；只有光标落在宠物身上、
  或右键菜单 / 对话框打开时，壳才临时接管鼠标
- 与浏览器页形态**完全共用**：同一台服务器、同一份配置（宠物 / 菜单 / 物理参数 / 对话记忆），
  设置页改一次，两边立即一致
- 壳本身不渲染任何东西——渲染、配置、状态全部来自服务器的桌宠页；服务器挂了壳会自动重试

## 绿色版使用（推荐，无需安装任何东西）

1. 解压 `dsh-pet-shell-*.zip` 到任意目录
2. 双击 `dsh-pet-shell.exe`
3. **首次启动**弹出设置窗：粘贴桌宠页完整地址（含 `?token=…`，来自服务器上桌宠服务
   启动横幅的「浏览器页」一行）→ 保存并启动
4. 之后桌宠常驻桌面，右下角**托盘图标**（马头）管理它

地址保存在 exe 同目录的 `config.json`（含令牌，已 gitignore）；删掉它再启动可重新设置。

## 托盘菜单 / 快捷键

| 操作                                  | 托盘菜单                        | 快捷键       |
| ------------------------------------- | ------------------------------- | ------------ |
| 显示 / 隐藏桌宠                       | 单击托盘图标，或菜单第一项      | `Ctrl+Alt+H` |
| **互动暂停**（点击穿透给桌面）        | 「互动」勾选项（勾=可点击宠物） | —            |
| 刷新页面（服务器更新后 / 页面异常时） | 刷新页面                        | —            |
| 改宠物 / 菜单 / 物理设置              | 打开设置页（浏览器）            | —            |
| 桌宠页另开浏览器                      | 在浏览器打开桌宠页              | —            |
| 退出                                  | 退出                            | `Ctrl+Alt+Q` |

### 互动暂停（0.2.0）

托盘取消勾选「互动」后，宠物对鼠标**完全隐身**：点击 / 右键全部穿透给下层窗口（做其它任务
绝不会点到它），光标划过也不接管、不弹悬浮提示；**动画与漫游照常自动播放**。状态记住
（config.json 的 `interactEnabled`），重启不丢。

## 边界（如实说明）

- 只覆盖**主显示器**（多屏第一版不做）
- 活动范围 = **工作区（不含任务栏）**：壳窗口铺 workArea 而非整屏，任务栏与窗口不重叠，
  底部不会被任务栏压住（0.2.0；代价是任务栏那条边缘宠物不会过去）
- 普通窗口、普通置顶窗都盖不过桌宠；**独占全屏游戏**会盖住它（系统层级限制）
- 页面右键菜单里的「桌宠设置」会用**系统浏览器**打开设置页（壳内不开第二个窗）
- 需要 Node ≥ 18 的机器仅在**开发模式**下需要；绿色版双击即用

## 开发 / 打包

```bash
cd shell
npm install
npm start       # 开发运行（读同目录 config.json，没有则弹首次设置）
npm run dist    # 打包 → dist/win-unpacked/（绿色版目录，双击 exe 即用）
```

> 服务器（无代码签名证书）上 `electron-builder --win zip` 会挂在 signApp 步骤——产物
> 其实已在 `dist/win-unpacked/`（zip target 只是把它压成 zip）。手动压缩即可：
> `cd dist/win-unpacked && zip -r ../dsh-pet-shell-win-x64.zip .`（或 Python zipfile，
> zip 根 = exe 所在层，解压直接双击运行）。

## 排障

- **shell.log**（exe 同目录）：壳的启动 / 页面加载 / 退出都有留痕；双击没反应先看它
- **双击没反应 = 大概率单实例锁**：0.2.1 起会弹原生提示框说明处理办法；旧版本请按：
  任务管理器结束所有 `dsh-pet-shell.exe` 进程后重试（异常关闭偶发锁未释放）

## 架构（与仓库其它部分的关系）

```
服务器（腾讯云 3080，dsh-pet-standalone.service）
  └─ /pet/ 桌宠页（渲染 / 配置 / 状态 / 记忆的唯一来源）
       ├─ 浏览器标签打开 → 形态 A（浏览器页）
       └─ 本壳全屏透明窗打开 → 形态 B（桌面壳）
壳侧只有三件事：透明全屏窗、鼠标穿透翻转、托盘。
页面通过 preload 注入的 window.petShell.setInteractive(on) 上报
「光标是否在宠物/浮层上」（sprite.setInteractive 的第二个上报口；
petBridge 是原 DSH 桌面形态的通道，本壳不注入，因此渲染始终走浏览器分支）。
```
